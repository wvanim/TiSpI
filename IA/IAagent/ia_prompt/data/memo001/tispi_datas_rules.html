Cette page montre comment les données Tispi complètes se décomposent en rôles exploitables (structure, spatial, décoratif)
Apprentissage de la structure. Voir ia_learn.md 

Piece root duration:200
  Track face[0:f0,[easeout, fade]; 100:f1,[fade]]
  Track pos[0:f0,[ease, slide]; 50:f1,[slide]]
  Track color[100:yellow,[ease, slide]; 150:red,[slide]]
  Face f0 image "myImage" w:800 h:400
  Face f1 text "Hello word" w:200 h:30

Tispi sépare les rôles des datas de l'animation :
En bleu : les datas de structure
En vert : les data de situation
En mauve : les datas de décoration

Avantage :
Le rôles sont positionés, donc repérable automatiquement.
Des échappement modifie le rôle de la zone.
Exemple : une situation deviendra struturel.
